# 变更历史

按版本倒序。更细粒度可看 `git log`。

## v1.0.17（2026-08-31）

- README 优化：新增主界面截图（`docs/工具页面.png`）置顶；重写为「快速开始（3 步）→ 界面导览 → 功能清单/详细配置」结构，便于使用者快速上手。

## v1.0.15（2026-08-31）

- 修复一键启动/单独启动后控制台窗口无任何输出：`os/exec` 会无条件设置 `STARTF_USESTDHANDLES` 把子进程 std 流接到 NUL，改为直接 `CreateProcessW`（不设该标志，与手动双击 bat 同语义）。

## v1.0.14（2026-08-31）

- 一键启动默认带上输入框里当前的 DSH 启动参数（非空才持久化）。
- 同一会话内修改启动参数立即生效，无需重启应用。

## v1.0.13（2026-08-31）

- WebView2 数据目录固定为 `%APPDATA%\DeepSeek Work`（与 config 同目录）。
- 预设行再点一次取消选中；启动按钮首帧即置灰。

## v1.0.12（2026-08-31）

- 启动/自定义按钮换位；未选中 bat 时一键启动彻底置灰。
- 应用与 exe 改名 **DeepSeek Work**；config 目录改名 `DeepSeek Work` 并自动迁移旧配置。

## v1.0.11（2026-08-31）

- 预设必须显式点行选中才可启动（未选中时启动按钮置灰，不再自动选中）。
- 「启动 DeepSeek Harness」及一键启动流程就绪后改为独立 Chrome 新页面打开（`chrome.exe --new-window`，Chrome 缺失回退系统默认浏览器）；移除窗口内 iframe 内嵌显示及相关样式。

## v1.0.10（2026-08-31）

- 预设行点选高亮 + 每行「删除」按钮（持久化，不删 bat 文件）。
- 启动按钮移至 Harness 卡片下方：「一键启动 bat 和 DeepSeek Harness」（完整流程）+「单独启动 bat」（只跑 bat，不轮询、不启 harness）。
- 去掉「在浏览器打开」按钮；新增「自定义启动 DeepSeek Harness」按钮展开/收起命令输入框（默认收起）。

## v1.0.9（2026-08-31）

- 回退误删：恢复「＋ 添加新的 bat」按钮与 `AddBat` 绑定。

## v1.0.8（2026-08-31）

- harness 更名 DeepSeek Harness（UI/提示文案）。
- 预设改由 `config.json` 的 `extraBats` 手动维护（此版本一度移除添加按钮，v1.0.9 恢复）。
- 新增单独启动脚本 `启动ai-starter.bat`；换用黑色 DSH 官方图标。
- `config.json` 固定存 C 盘 AppData。

## v1.0.7（2026-08-31）

- 预设改为手动维护（取消 `scanFolder` 目录扫描，字段仅作对话框默认目录）。

- 细窄内侧滚动条。

## v1.0.6（2026-08-31）

- 电脑信息多值行（磁盘/显卡/显示器）改单行「＋」连接格式；单硬盘不显示「主硬盘」标签。

## v1.0.5（2026-08-31）
